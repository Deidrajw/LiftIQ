Transfer LiftIQ data

Move browser-saved training records between LiftIQ domains. This tool runs entirely in this browser. It never uploads your export file to Hevy, Gemini, Cloudflare, or another server.

Open this page on the same device and browser profile where your saved records live. An export from the Cloudflare address cannot see the old Netlify domain's records.

1. Export this site's data

Save a JSON backup of known LiftIQ browser storage keys. It includes app state, saved training data, journal, cycles, settings and chats if present in this browser. It excludes credentials and other unrelated storage.

2. Import a backup

Select the JSON you exported from your previous LiftIQ site. You'll see the keys before anything changes.

No changes made.

Refresh LiftIQ after importing. Sign in again on the new site: authentication tokens are deliberately not transferred. Hevy remains the source of completed workout facts. The transfer cannot create missing Hevy records.
